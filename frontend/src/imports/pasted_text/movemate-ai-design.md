Design a professional, minimalist, modern web application prototype called:

“MoveMate AI”
Tagline: “Your personalised moving plan, made simple.”

MoveMate AI is an AI-powered relocation planning assistant designed specifically for Australian renters. The purpose of the MVP is to help users organise their move by generating a personalised moving plan based on their individual circumstances.

The interface should feel like a modern Australian technology startup: clean, trustworthy, calm, intuitive and professional. Avoid making it look overly futuristic or like a generic AI chatbot.

DESIGN STYLE

Use a minimalist UI with:

- Clean white/light background
- Dark navy or charcoal primary text
- One subtle accent colour such as blue
- Plenty of whitespace
- Rounded cards and buttons
- Simple modern typography such as Inter
- Clear visual hierarchy
- Minimal icons
- Subtle borders and shadows
- Consistent spacing
- Accessible contrast
- Responsive desktop-first layout
- Professional SaaS/product design aesthetic

Do NOT use:
- Gradients
- Excessive animations
- Cluttered dashboards
- Excessive illustrations
- Neon colours
- Complex charts
- A chatbot-heavy interface

The product should look realistic enough to demonstrate as a university capstone MVP and potentially show to recruiters.

CORE USER JOURNEY

Create a clickable prototype covering this journey:

Landing Page → Create Moving Plan → Enter Moving Details → Preferences → AI Plan Generation → Personalised Dashboard → Task Details → Timeline → Packing Suggestions → Profile/Settings

RESPONSIBLE AI DESIGN

Include subtle but visible responsible AI elements throughout the prototype.

The application should clearly communicate:

“AI-generated recommendations are provided for planning support only. Always verify important information before acting on it.”

Do not claim that the AI provides legal, financial or professional advice.

PRIVACY

Only collect information required for generating relocation recommendations.

Include simple privacy messaging rather than complicated legal text.

ACCESSIBILITY

Design the interface according to WCAG 2.2 principles:

- Clear contrast
- Readable font sizes
- Logical navigation
- Clear button labels
- Avoid colour-only indicators
- Accessible form labels
- Consistent layout

IMPORTANT MVP SCOPE

Keep the prototype focused on the core value proposition:

USER INPUTS
↓
AI PERSONALISATION
↓
MOVING PLAN
↓
CHECKLIST + TIMELINE + REMINDERS + PACKING SUGGESTIONS

Do not add unnecessary features such as:
- Payments
- Real estate marketplace
- Removalist booking
- Social networking
- Complex financial management
- Full messaging system

The prototype should demonstrate the feasibility of MoveMate AI as an MVP, not a complete commercial platform.

Create a consistent design system across all screens and ensure the prototype feels like one cohesive professional product.
