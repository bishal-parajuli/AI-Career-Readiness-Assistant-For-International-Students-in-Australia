# Contributing

This repository is the Part A capstone submission for PROF909 (Information Technology Project Part A) and will continue as the working repository for PROF910 (Part B).

## How this project will be developed in Part B

- Development follows an Agile Scrum approach with three iterative sprints (see [Project Proposal](./docs/Project_Proposal.pdf), Section 8–9).
- Work is tracked on the [Project Board](../../projects), with tasks moving from Backlog → Sprint Planning → In Progress → Review → Done.
- All commits are made directly by the project owner (Bishal Parajuli), as this is an individual capstone project.
- Feedback from the academic supervisor is incorporated at each sprint review.
- Responsible AI, privacy, and ethics safeguards (see [Ethics section](./README.md#ethics-privacy-and-responsible-ai)) are applied throughout development, not only at the design stage.

## Questions or feedback

Feel free to open an issue on this repository if you'd like to leave feedback or ask a question about the project.
